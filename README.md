# KompaktDevice

The hardware side of KompaktOS on the Mudita Kompakt: the kernel, the e-ink
driver, the LineageOS recovery, the vendor partition and the device tree.

**To install KompaktOS**, follow the guide at [kompaktos.gez.im](https://kompaktos.gez.im).
The kernel and recovery image is in [Releases](https://github.com/gezimos/KompaktDevice/releases).

Sister repo: [KompaktOS](https://github.com/gezimos/KompaktOS), the LineageOS
system image that runs on top of it.

```
KompaktOS      the ROM      system.img
KompaktDevice  the device   boot.img (kernel + recovery), vendor.img, dtbo
```

## What it builds

| Image | What it is |
|---|---|
| `boot.img` | Our kernel, from Mudita's published 1.5.0 source with our patches, and the LineageOS recovery |
| `vendor.img` | Mudita's vendor with our e-ink modules, pictures, access rules, fingerprint navigation and fixes |
| `dtbo.img` | Built from source, identical to Mudita's, so there is no need to flash it |
| full update package | This repo's boot and vendor with KompaktOS's system, in one zip, installed from the LineageOS recovery |

## What ours adds over Mudita's

- Partial e-ink updates and an Auto mode: fast while the screen moves, clean
  once it settles.
- An always-on display that lets the phone sleep: 3–4% overnight instead of
  about 20%.
- Correct battery capacity and health, a real cycle count, and a charge limit
  that is enforced.
- Scrolling with the fingerprint sensor, and a sleep screen picture of your own.
- A LineageOS recovery that installs KompaktOS updates over USB or from the SD
  card, in black on white.

## Building

| What | How |
|---|---|
| Kernel | `kernel/build-kernel.sh` with `kernel/patches/`; see [kernel/README.md](kernel/README.md) |
| Recovery | `patches/` applied to LineageOS, then `tools/pack-recovery-boot.sh`; see [patches/README.md](patches/README.md) |
| Vendor | `vendor/scripts/build-vendor.sh <build number>` on a Linux host; see [docs/Vendor.md](docs/Vendor.md) |
| Update package | `tools/make-full-ota.sh`; see [tools/README.md](tools/README.md) |

The kernel must be built with `CROSS_COMPILE=aarch64-linux-gnu-`. With
`aarch64-linux-android-` it builds and never boots.

## Layout

```
kernel/    kernel patches and build scripts
patches/   patches to LineageOS itself: the recovery and its installer
device/    the LineageOS device tree, for the recovery
vendor/    scripts and tools that build vendor.img (Mudita's files are not committed)
tools/     boot image, update package and picture tools
assets/    our boot logo, sleep screen and power-off pictures
dtbo/      building the dtbo from source
dts/       device trees taken from the shipping images
docs/      how each part works, in detail
```

## Mudita's source

Two things the kernel source refers to are not in it. `meink.ko`, the panel
driver, is proprietary, so it comes from the vendor partition; its GPL halves,
`meink_hal.ko` and `meink_loader.ko`, are published and we build them.
`cust.dtsi` is generated by MediaTek's DrvGen from the published `.dws`; we
build it, identical to theirs (kernel patch 0021).
