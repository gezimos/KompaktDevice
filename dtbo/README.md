# dtbo

Builds `dtbo.img`, the device tree overlay, from Mudita's published kernel
source. The result is byte-identical to the `dtbo.img` Mudita ship, so there is
no need to flash it. It is the baseline to diff against before changing the
board's hardware description.

```
gencust.py   generates arch/arm64/boot/dts/Kompakt/cust.dtsi from a decompiled stock overlay
mkdtbo.py    packs an overlay into a dtbo.img shaped like stock
```

The published source is missing `Kompakt/cust.dtsi` (normally generated by
MediaTek's DrvGen) and the Makefile line for `Kompakt.dtb`. Kernel patch 0021
adds both, with `cust.dtsi` already generated by `gencust.py`.

## Build

```sh
# kernel tree prepared as in kernel/README.md, with patch 0021 applied
M="ARCH=arm64 O=out LLVM=1 LLVM_IAS=1 CROSS_COMPILE=aarch64-linux-gnu-"
make $M Kompakt_defconfig
make $M mediatek/Kompakt.dtb

python3 dtbo/mkdtbo.py out/arch/arm64/boot/dts/mediatek/Kompakt.dtb stock-dtbo.img dtbo.img
```

`mkdtbo.py` takes a stock `dtbo.img` as the reference for its shape and the
MediaTek certificate tail. It prints `IDENTICAL_TO_STOCK` when nothing has
changed. After any change the tail is no longer a valid signature, which an
unlocked bootloader does not check.

The overlay inside is the same in every Mudita release from 1.1.0 to 1.6.0,
Global and USA; only the certificate tail differs.

## The base tree

The other half of the device tree, the `dtb` section of `boot.img`, also builds
byte-identical from the source as published:

```sh
make $M mediatek/mt6761.dtb
python3 dtbo/mkdtbo.py out/arch/arm64/boot/dts/mediatek/mt6761.dtb stock-boot-dtb boot-dtb
```

## Regenerating cust.dtsi

```sh
dtc -I dtb -O dts stock-overlay.dtb > stock.dts
python3 dtbo/gencust.py stock.dts cust.dtsi
```

It takes fragments 28 to 60 of the stock overlay, the block DrvGen generates,
and turns them back into `&label { ... };` nodes. Use the kernel's own `dtc`
(`make $M scripts/dtc/`).

## Changing the overlay

A wrong overlay means a phone that does not boot, and `boot` carries the only
recovery. Diff before flashing; every difference must be one you meant:

```sh
dtc -I dtb -O dts -s ours.dtb  > ours.dts
dtc -I dtb -O dts -s stock.dtb > stock.dts
diff ours.dts stock.dts
```

- The e-ink SPI clock in the overlay is ignored: the driver sets its own. That
  is a kernel change.
- Keep the NFC and camera nodes. The Kompakt has NFC and a rear camera, and the
  rear camera is also exposed as a front one for apps that require face
  verification.
- The charger settings are not in the overlay but in the base tree.

More in [docs/Device-tree.md](../docs/Device-tree.md).
